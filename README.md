# CS-Array-Project
Project description
Array manipulations.
This project has functions in it that will allow users to manipulate an array of numbers.This program will allow you to check if a certain number exists in the array with return of index where number exists.Modify number of given index with return of old and new value.Add value at the end of array.Removing an number at given provided index.
Instruction
Make sure your array file named “A1input.txt” in project root depository.
Integers separated by spaces.
On start program will load al integer and display how many if them were loaded in. 
Once everything done you will be in main menu asked questions of which operation you would like to preform.
Press 1: To search for a number. 
Press 2: To modify an existing value. You will be asked for the index and the new value.
Press 3: To add a value to the end of the array.
Press 4: To remove a value at a specific index.
Press 0: To exit the program.
